# 迈从 MCHOSE 协议笔记

状态：**仅识别**。

## 为什么这个品牌最好啃

官网的网页驱动（`mchose.com.cn`）前端是**未混淆的 Vite 构建产物**，协议代码直接可读，不用反编译。抓包只是用来交叉验证。

浏览器里也能自取证：打开网页驱动 → 连接设备 → F12 → 切换一个灯效，Console 会打出 `[webHID:发送Feature]` 之类的日志。

## 设备与传输

| 系列 | VID | 通信 | 证据 |
|---|---|---|---|
| Sinowealth 方案（多数鼠标） | `0x41E4` | Feature Report 9，读 519 字节 / 写 519 字节配置块 | 社区文档 |
| 磁轴键盘（Ace / Jet / Mix / Zero） | `0x3837` | Feature Report 9 | 社区文档 |

已记录的结构（来自公开逆向，未在本仓库真机复核）：

- 读配置：`84 00 00 01 00 80 00` + 512 个 `00`
- 写配置：`04` + 134 字节配置 + 补零到 519
- 应答形如 `[09 84] + 134 字节`，`lightType` 在偏移 38、`lightMode` 在偏移 39

磁轴键盘是复合 HID，三个接口分工明确：

| 接口 | 作用 |
|---|---|
| 0 | 普通键盘 |
| 1 | 配置通道 |
| 2 | 鼠标 / 消费类 / 高级键（SOCD、RS、DKS、MT、TGL） |

高级键走接口 2 的 16 字节报告，语义解析不在本机内核里做，所以 Linux 下要额外的用户态桥接——Windows 没有这个问题。
